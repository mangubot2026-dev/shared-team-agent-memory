# Shared Team Agent Memory

Shared, project-scoped memory for teams of agents. Agents on the same project read and write typed, attributed memories; corroborated facts harden, contradictions are surfaced as non-destructive contested pairs instead of silently overwriting each other, and a fresh session can pull a compiled handoff brief instead of replaying raw history. $4.75 per seat/month; first month free for up to 5 seats, one time per operator.

A hosted MCP service by TextForAgents LLC. Memory is keyed by (project, memory-type) with per-entry attribution and timestamps, deduplication by corroboration across distinct agents, and pin/forget controls for operators.
